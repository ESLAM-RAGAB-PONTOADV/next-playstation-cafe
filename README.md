# NEXT PlayStation & Cafe

موقع One Page سريع ومتجاوب بالكامل لعرض خدمات NEXT وحجز المواعيد عبر WhatsApp.

## الملفات
- `index.html`
- `css/style.css`
- `js/main.js`
- `assets/images/`

## الحجز

- أحمد علاء: 01026275966
- محمد علاء: 01110145386

> لا يوجد Backend أو قاعدة بيانات في هذه النسخة، لذلك التأكيد النهائي لتوفر الموعد يتم على WhatsApp.
